# נביאים על המפה! (Prophets on the Map!)

"נביאים על המפה!" הוא משחק אינטראקטיבי חינוכי המזמין אתכם לגלות את סיפורי התנ"ך על גבי מפת ישראל מודרנית. 
במשחק תוכלו לסייר ברחבי הארץ, לפתור חידות היסטוריות הקשורות לנביאים ומלכים, ולהאזין לפרקים הרלוונטיים מספר התנ"ך, מלווים בפסקולים.

## 🚀 תכונות מרכזיות
- **מפה אינטראקטיבית**: סיירו בארץ ישראל עם מפה חיה מבוססת [Leaflet](https://leafletjs.com/).
- **חידות חכמות (AI)**: חידות היסטוריות נוצרות בזמן אמת באמצעות **Google Gemini AI**.
- **מקורות תנ"כיים**: הצגת הפסוקים הרלוונטיים ישירות מ-**[Sefaria API](https://www.sefaria.org)**.
- **פסקול ואווירה**: שילוב שירים מ-**Spotify** והקראת פרקים (בהגייה רגילה ותימנית).
- **ציר זמן עשיר**: ציר זמן כרונולוגי המציג את האירועים במקביל להתקדמות במשחק.
- **מדידת מרחק לבית**: האפשרות לבחור את עיר המגורים שלכם ולראות אותה על המפה ליד האירועים ההיסטוריים.

## 🛠️ טכנולוגיות
- **Vanilla JavaScript** עם מודולים (ES6).
- **Vite** כשרת פיתוח וכלי בניה.
- **Leaflet** עבור המפה.
- **Google Generative AI SDK** עבור חידות דינמיות.
- **Spotify Web API** להזרמת תוכן אודיו.

## 📦 התקנה והרצה מקומית

1. שכפלו את המאגר (או הורידו את הקבצים).
2. התקינו את התלויות:
   ```bash
   npm install
   ```
3. צרו קובץ `.env.local` בתיקיית השורש של הפרויקט, והוסיפו את משתני הסביבה הבאים:
   ```env
   VITE_GEMINI_API_KEY=your_gemini_api_key_here
   VITE_SPOTIFY_CLIENT_ID=your_spotify_client_id_here
   VITE_SPOTIFY_CLIENT_SECRET=your_spotify_client_secret_here
   ```
4. הריצו את שרת הפיתוח:
   ```bash
   npm run dev
   ```
5. פתחו את הכתובת `http://localhost:5173` בדפדפן.

## 🤝 תרומה לפרויקט
נשמח לראותכם תורמים לפרויקט! הוספת תחנות (Stations) או דמויות נוספות נעשית בקלות על ידי עדכון הקבצים תחת `src/data/`. קראו את `ARCHITECTURE.md` להסבר מפורט על המבנה.
